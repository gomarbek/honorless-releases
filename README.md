## Getting started

1. **Install the desktop app** with the button above.
2. **Install the Honorless addon** from [Wago](https://addons.wago.io/addons/honorless).
3. **Open the app, sign in with Discord and link your character.** The app picks up what the addon
   records and syncs it to [honorless.gg](https://www.honorless.gg).

Full walkthrough: [honorless.gg/desktop](https://www.honorless.gg/desktop).

## "Windows protected your PC"

The installer isn't code-signed yet, so Windows SmartScreen may warn you the first time. Click
**More info**, then **Run anyway**.

## Verify your download

Each release lists the installer's SHA-256 in `SHA256SUMS.txt`. In PowerShell:

```powershell
Get-FileHash .\Honorless-Setup.exe
```

## Updates

The app updates itself: when a new version is out, it offers **Update and restart**.
